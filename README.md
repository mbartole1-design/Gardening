# Gardening

Notes and tools for Milan's Wenatchee, WA garden.

## Tools

- [`rain-gauge`](rain-gauge): animated year, month and week rain gauges with 1996–2025 averages. Double-click `index.html`.

## Claude mods

- [`mods/datebook-tabs`](mods/datebook-tabs): project threads as date-book tabs on the right edge of the screen.

Install with `/plugin install datebook-tabs --marketplace mbartole1-design/Gardening`.
